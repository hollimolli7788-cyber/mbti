# 🧠 Python MBTI Personality Test

파이썬 콘솔 기반의 간단한 성격유형(MBTI 스타일) 검사 프로그램입니다. 4가지 기본 성격 차원(E/I, S/N, T/F, J/P)에 대한 문항에 답하여 사용자의 성격 유형을 측정하고 분석 결과를 제공합니다.

---

## 📌 주요 기능 (Features)

- **4대 성격 차원 분석**: E/I(외향/내향), S/N(감각/직관), T/F(사고/감정), J/P(판단/인식)의 4개 축으로 점수 집계
- **대화형 CLI 인터페이스**: 콘솔에서 질문에 번호(1 또는 2)를 선택하여 간편하게 테스트 진행
- **예외 처리 (Input Validation)**: 잘못된 입력(문자, 범위 외 숫자 등) 시 경고 메시지와 함께 재입력 요청
- **상세 결과 리포트**: 도출된 4글자 성격 유형 및 각 차원별 점수 분포 시각화

---

## 🏗️ 프로그램 구조 (Architecture)

프로그램은 단일 객체지향 클래스(`PersonalityTest`)로 구성되어 있어 확장 및 배포가 간편합니다.

```text
mbti_test.py
 └── class PersonalityTest
      ├── __init__()          # 질문 데이터 정의 및 점수판 초기화
      ├── run_test()          # 질문 출력 및 사용자 입력(1/2) 수집 (예외 처리 포함)
      └── calculate_result()  # 각 차원별 점수 비교 및 최종 MBTI 유형/상세 결과 출력
